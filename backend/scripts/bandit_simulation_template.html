Prompt variant bandit — simulated convergence

Real feedback volume is too small right now to show this on live traffic, so this is a simulation: 4 synthetic prompt variants with fixed (hidden-from-the-algorithm) true win rates, run for rounds and averaged over independent trials so the curves show the algorithm's actual behavior rather than one run's luck. It shows what Thompson Sampling does with the same kind of feedback a real avatar would generate — pick winners faster than a coin flip, without a fixed A/B split.

Cumulative regret

Regret = how much win-rate was left on the table each round versus always picking the best variant. Lower and flatter is better. Random selection keeps accumulating regret at a constant rate forever; Thompson Sampling's curve bends toward flat as it learns which variant is best.

Selection share over time (Thompson Sampling)

Share of impressions each variant has received, cumulatively, round by round. Starts near an even split (the prior has no opinion yet) and converges toward favoring the best-performing variant as feedback accumulates.
